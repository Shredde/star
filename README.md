# 星际漫游 - 简单 Web 项目

这是一个使用原生 **HTML + CSS + JavaScript** 构建的静态网页示例。页面展示了一个虚构的“星际旅程”主题站点，包含响应式布局、随机太空知识按钮以及旅程规划器等模块，适合初学者参考。

## 功能一览

- ✅ 顶部导航与沉浸式头图
- ✅ 随机太空知识按钮（原生 JS 交互）
- ✅ 太空旅程规划表单，自动生成概要
- ✅ 自适应布局，移动端体验良好

## 本地预览

```bash
python -m http.server 8000
```

启动后访问 [http://localhost:8000](http://localhost:8000) 即可查看页面。

> 如果你使用的是 Node.js，也可以选择任何静态服务器（如 `npx serve`）来预览。
