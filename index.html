开启你的第一次太空之旅

"星际漫游" 是一个简单的 Web 小项目，展示了如何组合 HTML、CSS 与 JavaScript 打造一个视觉清晰、交互友好的单页体验。

项目特色

结构清晰

简洁的 HTML 语义结构，易于拓展与维护。

响应式布局

借助 CSS Grid 与 Flexbox，内容在不同设备上都能舒适呈现。

轻量交互

使用原生 JavaScript 实现按钮交互，兼顾性能与易理解性。
